# Flappy Bird Game

A browser-based Flappy Bird clone built with HTML Canvas and JavaScript.(Desktop recommended)

## Features
- Gravity mechanics
- Pipe generation
- Keyboard controls (Spacebar and Arrow Up)
- Collision detection
- Score tracking
- Restart option without refreshing the page

## Tech Stack
- HTML5 Canvas
- CSS3
- JavaScript

## Live Demo
[https://warisha-flappy-bird.netlify.app]

## How to Run
1. Clone this repository
2. Open `index.html` in your browser
